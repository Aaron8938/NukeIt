# NukeIt

Windows 上有些东西用资源管理器就是删不掉：被程序占着、带只读和系统属性、路径太长、目录被某个终端当成了工作目录。

这个工具专门对付这些。双击 `NukeIt.bat`，把删不掉的东西拖进黑窗口，按一次回车。

```
==============================================================
  NukeIt 1.2   ·   Windows 强制删除工具
  三级降级：常规 → 强开句柄 → 重启时删除
==============================================================

把文件或文件夹拖进本窗口（可连续拖多个），拖完按回车：
> "D:\Downloads\删不掉的文件夹"
[1] D:\Downloads\删不掉的文件夹
    类型      文件夹
    内容      25 个文件, 6 个文件夹, 30.32 MB
    属性      普通
    占用      未检测到

--------------------------------------------------------------
[1] 删除中 … 删不掉的文件夹
    成功 （25 文件 · 7 目录 · 手段 L1）

==============================================================
  成功 1
==============================================================
```

## 特点

- **三级降级**：常规删除 → 强开句柄删除 → 登记重启时删除，前一级不行自动往下走。
- **删不掉会告诉你谁占着**：报出进程名和 PID，你确认之后结束进程，只重试失败的那部分，不用整轮重来。
- **不啰嗦**：拖进来按一次回车就开始删。想要先看清单再确认，加 `--ask`。
- **长路径和怪名字**：超过 260 字符的路径，以及名字里带空格、逗号、`&`、`#`、括号、中文、单引号的，都能处理。
- **链接不穿透**：junction 和符号链接只删链接本身，绝不进入它指向的目录。
- **零依赖**：只用 Python 标准库，单文件。

## 使用

1. 双击 `NukeIt.bat`。
2. 从资源管理器把文件或文件夹拖进窗口，可以连续拖多个。
3. 按一次回车。删除完窗口自动关闭。

删不掉的时候窗口会停住，把失败项和原因列出来，按任意键关闭。

## 命令行

```
nuke.py [路径 ...] [选项]
```

| 参数 | 说明 |
|---|---|
| 无参数 | 交互模式，等拖入 |
| `--ask` | 先列清单并等一次确认再删 |
| `--dry-run` | 只体检和预览，不真删 |
| `--no-kill` | 不结束占用进程 |
| `-y`, `--yes` | 全自动，不等确认也不结束进程 |
| `-h`, `--help` | 帮助 |
| `-v`, `--version` | 版本 |

预览一个目录有多大、里面有多少文件：

```
python nuke.py "D:\某个目录" --dry-run
```

## 删除原理

| 级别 | 做法 | 应付的情况 |
|---|---|---|
| L1 | `DeleteFileW` / `RemoveDirectoryW`，删除前先剥掉只读、隐藏、系统属性 | 属性导致删不掉；对瞬时占用先重试几次 |
| L2 | `CreateFileW(DELETE)` + `FILE_SHARE_DELETE` + `FILE_FLAG_DELETE_ON_CLOSE` | 句柄还开着、但允许删除共享的文件 |
| L3 | `MoveFileExW(MOVEFILE_DELAY_UNTIL_REBOOT)`，失败则写 `PendingFileRenameOperations` | 重启时才释放的文件，登记到下次开机删除 |

L1 遇到共享冲突会重试，但全局有次数上限，避免上万个文件被占用时一直卡着不动。

## 安全边界

这些位置直接拒绝，不给二次确认的机会：

- 盘符根目录
- `C:\Windows` 整棵树
- `C:\Program Files`、`C:\Program Files (x86)`、`C:\ProgramData` 的根目录
- 用户目录、当前用户主目录
- 桌面、文档、下载、图片、音乐、视频（会从注册表读取真实位置，重定向到其它盘也能拦住）
- 各盘的回收站和 `System Volume Information`
- 工具自身所在目录及其上级、当前工作目录

另外：

- 层级过浅（比如 `D:\某个文件夹`）或目标特别大（超过 20GB 或 5 万个文件）时，会要求输入大写的 `YES` 才能继续。
- 判断路径前会先剥掉 `\\?\` 前缀、去掉尾部空格和点，防止用特殊写法绕过上面的拦截。
- 删除前会显示文件数、总大小和占用进程。
- 删除不进回收站，删了就没了。

## 已知限制

- 不夺取文件所有权。被 TrustedInstaller 之类的账户保护的系统文件仍然删不掉。
- L3 需要管理员权限，普通用户跑只能删到 L2。
- 控制台单行输入有长度上限（约 8000 字符），一次拖太多可能被截断，分几次拖。
- 只支持 Windows。

## 环境

Windows 10 / 11，Python 3.6 以上（在 3.14 上实测过）。

`NukeIt.bat` 会依次尝试 `py -3`、`python`、ArcGIS Pro 自带的 Python。都没找到时会退到一个只用 `rd` / `del` 的简化模式，只能处理基本删除。
